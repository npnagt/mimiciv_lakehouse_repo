P6 Render Probe

Measures how long a browser takes to actually paint a chart for each insight in the time-to-insight battery, at the result-set size Athena returned. This is the render component of time_to_insight = data-ready + fetch + render. The harness assumes a fixed 500 ms render allowance; this page measures the real number so that assumption can be checked (or replaced).

Method: each chart is built 5× with animation.duration = 0; the timer runs from just before new Chart() to the onComplete callback (first paint). First run discarded, median of the rest. Synthetic data at the measured row count — render cost is driven by point count and chart type, not the values. Chart.js 4.4.1. Two stress rows (2 000-point line, 5 000-point scatter) bracket anything the Gold schema would send a dashboard.
